# 《斯泰尔斯庄园奇案》玩法介绍 · 测试者版

这是一份给人读的测试指南：**先讲怎么玩，再讲测什么、哪些现象不是 bug、bug 怎么报**。

成品：

* Windows：`Builds/Windows/Styles.exe`（双击即玩，窗口模式更利于截图）
* Android：`Builds/Android/Styles.apk`（横屏）

## 一、这是什么游戏

阿加莎·克里斯蒂《斯泰尔斯庄园奇案》的视觉小说改编。你是黑斯廷斯，跟着波洛办案：
**9 章、437 句台词、正文约 2.26 万字、约 100 分钟**，其中穿插 8 道推理题、5 场现场调查、3 场询问、6 题最终指认。
（2026-09-13 这一版按原著扩写了两轮：正文从 8995 字涨到 22624 字。补回的内容包括宅子与人物描写、
悲剧之夜的细节、勘查的七件物证、调查庭的全部证词、伪造笔迹与不在场证明、夜探书房，
以及保释期间的家庭戏、玛丽与鲍尔斯坦的支线、辛西娅与劳伦斯的感情线、雷克斯太太农舍的场景、
终章里逐节拆解机关的十段长篇解释。）

结局按「最终指认」的正确数评级：全对 → **S**，错 1 题 → A，错 2 题 → B，错更多 → C，
**第一题就答错** → D（分歧结局）。

## 二、怎么玩（30 秒上手）

1. 标题画面点 **开始案件调查**。想接着上次的进度就点 **继续上次调查**（游戏会每 8 条指令
   或每 20 秒自动存一次档）。
2. **点屏幕任意位置**推进对话；一句话正在逐字显示时，点一下会先把这句显示完。
   * 键盘也行：**空格 / 回车**推进，**Esc** 打开菜单，**按住 Ctrl** 快进。
   * 对话框右上角的 **自动**：念完一句自动翻到下一句（间隔在「设置 → 自动播放间隔」里调）。
   * 对话框右上角的 **快进**：几乎立刻翻页。
3. 右上角四个按钮随时可用：**笔记本**（证据）/ **人物**（人物档案与关系图）/ **回顾**（对话回顾）/ **菜单**。
4. 遇到玩法界面就按提示操作：选选项、点推理答案、点场景里的热点、问话、最后指认凶手。
5. 走到 **结算报告** 就是通关：上面有得分、失误次数、收集到的证据、用时和评级。

## 三、五个玩法系统怎么用

| 系统 | 界面长什么样 | 怎么算通过 | 测试时的重点 |
|---|---|---|---|
| **选项** | 屏幕中部竖排的选项卡片，带「提示」的选项下面有一行小字 | 点任一项继续 | 两项都能点；点了之后选项应立刻消失、剧情继续 |
| **推理题**（灰色小细胞） | 大卡片，上面是题目，下面是若干选项 | 选对才出现「继续 →」 | 故意选错：应**变红并显示波洛的点评**，同时「失误 +1、得分 −3」；可以一直重选，答对为止 |
| **现场调查** | 场景图上散布着金色方框热点，左上角有开场提示，右上角有「已发现 N / M」 | 点满要求数量的热点后出现「结束搜寻 · 继续剧情 →」 | 每个热点都必须点得到（不能有点不到的角）；点过的热点会变暗但仍可回看说明 |
| **询问** | 左列人物、中间话题、右列口供，底部有「→ 问一个问题」「还需再问 N 个问题」 | 问够要求数量后出现「结束询问」 | 没解锁的话题点了只提示、不算数；每问完一个话题要点「← 换一个问题」回列表 |
| **最终指认** | 一题一屏，下面是 4 个候选 | 6 题作答完进入结算 | 选定后其它选项应变灰不可点；每屏都要有「继续 →」 |
| **证据笔记本** | 顶部 4 个筛选（全部 / 物证 / 证词 / 推论）+ 左列列表 + 右侧详情 | — | 新证据应有右上角「＋ 已记入笔记本：xxx」的飘字提示 |

## 四、测试重点：这几条最容易出问题（请重点打）

这些是自动化测试专门盯过的边界，人工复测一次会更放心：

1. **演出中途开弹层、返回标题**（HUD 永远在最上面，随时可以点）
   * 在**调查界面里**点「菜单 → 返回标题」：标题画面必须是干净的，**不能残留调查面板**；
   * 在**推理 / 询问 / 指认界面里**做同样的事；
   * 在**章节卡刚出现时**就返回标题：等 5 秒，剧情**不能自己继续演**（这一条以前会漏）。
2. **反复开新游戏**：返回标题 → 再「开始案件调查」→ 剧情必须从第一章第一节重新走，不能出现
   「屏幕有界面但点了没反应」（旧的 `Running` 标志 bug）。
3. **读档**：
   * 从标题「继续上次调查」；从菜单「读取存档」；
   * 读档后对话框要出现、进度回到存档位、证据数量与存档一致；
   * 把 `%USERPROFILE%\AppData\LocalLow\LorXer Studio\Styles\saves\slot1.json` 内容改坏再读：
     应当**提示读不出**而不是崩溃或白屏。
4. **自动播放 / 快进**：
   * 打开「自动」后**什么都别点**，剧情应自己往下走；
   * 自动播放时打开笔记本 / 菜单：剧情**必须停住**，关掉弹层后继续；
   * 快进遇到选项 / 推理题应停下等你操作。
5. **窗口尺寸与手机比例**：把窗口拉成 16:9、20:9（超宽）、4:3（近方）三种都跑一下：
   界面不能被裁、按钮不能跑出屏幕、调查热点不能互相压住。Android 上重点看刘海 / 挖孔区域
   （界面走安全区适配）。
6. **设置**：拖 4 条滑条（文字速度 / 自动播放间隔 / 音乐 / 音效）、切画质 4 档、切全屏，
   退出再进：设置应当保留；把 `settings.json` 改坏，游戏应当回退默认值而不是崩。
7. **存档槽**：3 个手动槽都能存、都能读；存档摘要上的时间 / 章节 / 证据数应当和实际一致。
8. **连点**：快速连点推进，剧情不应乱序、不应跳句、不应重复发证据。

## 五、这些现象**不是** bug（先别报）

| 现象 | 原因 |
|---|---|
| 点「→ 点击继续」的位置没反应，点别处才推进 | 已修。若仍出现请报（这是回归） |
| 一句话只显示了一半 | 点一下会先把整句显示完；这是打字机效果 |
| 通关时证据显示 31/36，听说能拿 35 | **只问够最低要求的询问数量就结束**，会少拿几条可选线索。3 场询问共 35 个话题、16 个发线索，而系统只要求问 3+3+4=10 个。把话题问全 → 35/36。差的 1 条永远拿不到：第三章有个选项分支与另一条证据互斥，属设计 |
| 全程没有音乐和音效 | **确实没有**：这一版工程里一个音频文件都没有，剧本里也没有音频指令。这是已知缺口，不是 bug |
| 有些配角没有立绘，显示成一个带姓氏的徽记 | 15 个人物里 5 个没有立绘，已知缺口 |
| 菜单面板中间空一大块 | 版式问题（7 颗按钮贴在卡片底部），已知，不影响功能 |
| 章节卡刚出现那一下几乎是黑的 | 章节卡是淡入的（0.5 秒），属正常演出 |
| 结局评级为 C 或 D | 取决于你答对几题；第一题答错一定是 D（分歧结局） |
| 知识卡是一片空白（只有标题和「明白了」） | **修好了**：转换脚本以前把知识卡正文整段丢掉了，4 张卡都是空壳。现在 4 张卡都有正文 |
| 人物关系图里名字糊在一起、头像和方框错位 | **修好了**：重新排了关系图（自动保证名字与头像互不重叠）。若还有压住的，请报 |
